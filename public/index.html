Photo Sheet Printer

Nine photos, one sheet, nothing thrown away.

Your photos never leave this tab — there is no server to send them to.

This page needs to be served over HTTP. It looks like you opened index.html directly from your file manager, and the browser's security policy blocked the scripts. From the project folder run python3 -m http.server 8080 --directory public, then open http://localhost:8080. See the README for the Docker route.
